# EWF 9000: 100 tweaks

Small jobs, each one commit. None of them needs a decision from Ryan. Read `CLAUDE.md` first.

**How to work this list**

- Go top to bottom inside a section; sections can be done in any order. Section B (tests) first is a good idea: it makes everything after it safer.
- One tweak, one commit. Tick the box in the same commit. If a tweak turns out to be wrong or already done, tick it and say why in the commit message.
- After each tweak: `node build.js`, type-check, and the test for the section you touched. After every ten: `node test-uni.js universes/public_domain.json 60` and `app/tests/journey.js`.
- Do not start the big features from `TASKS.md` under a tweak. Do not polish the card editor in `app/src/screens/booking/Card.tsx` and `Editor.tsx`: task 3 replaces it.
- Keep every rule in `CLAUDE.md`: no external assets, original names only, no dice wording, every control reachable by all four inputs.

# Where the plans live

Nothing here has been deleted. This page says what each planning file is for and which ones are current.

| File | What it is | Current? |

| `CLAUDE.md` | How the project works: commands, layout, the rules every change follows. | Yes. Read first. |

| `docs/map.md` | Generated map of the engine files (`node tools/map.js`). | Yes, regenerate after adding files. |
